## Анализ исходных данных проекта (dataset)

### 1. Пункты навигации (на основе navigation.json)
На странице должно быть организовано навигационное меню, содержащее **4 пункта**:
* **О курсе** (устойчивый идентификатор `target`: `about`)
* **Направления** (устойчивый идентификатор `target`: `tracks`)
* **Расписание** (устойчивый идентификатор `target`: `schedule`)
* **Регистрация** (устойчивый идентификатор `target`: `signup`)

### 2. Структура разделов страницы
Каждый пункт навигации ведет к соответствующему разделу (`<section>`) на главной странице с использованием ID в качестве якоря:
* `<section id="about">` — Раздел «О курсе»
* `<section id="tracks">` — Раздел «Направления» (информационный блок с карточками)
* `<section id="schedule">` — Раздел «Расписание»
* `<section id="signup">` — Раздел «Регистрация»

### 3. Карточки контента для вывода (на основе content.csv)
В разделе «Направления» (`#tracks`) необходимо вывести **6 карточек** учебных модулей:
1. **HTML** (ID: `1`, Категория: `Основа`, Описание: `Структура и разметка`, Сложность: `8`)
2. **CSS** (ID: `2`, Категория: `Оформление`, Описание: `Стили и адаптивная верстка`, Сложность: `9`)
3. **Git** (ID: `3`, Категория: `Инструменты`, Описание: `История изменений и контроль версий`, Сложность: `7`)
4. **Forms** (ID: `4`, Категория: `HTML`, Описание: `Пользовательские формы`, Сложность: `6`)
5. **Accessibility** (ID: `5`, Категория: `Качество`, Описание: `Доступность интерфейсов`, Сложность: `10`)
6. **DevTools** (ID: `6`, Категория: `Проверка`, Описание: `Исследование элементов в браузере`, Сложность: `8`)
