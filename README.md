# Информационный портал факультета

Лабораторная работа №1 по курсу «Технологии разработки программного обеспечения» (ТРПО).
**Выполнила:** Студентка Алина Меркулова

## Структура проекта и HTML-разметка
Проект организован в виде модульной структуры каталогов и файлов:
* `index.html` — главный семантический каркас веб-страницы.
* `README.md` — техническая документация к проекту.
* `/css/styles.css` — внешний вид, сетки и стили доступности.
* `/images/` — медиа-ресурсы проекта (`logo.svg` в качестве главного баннера и `cover.svg` как обложка курса).
* `/data/` — исходные файлы данных (датасет).

**Семантические особенности HTML:**
Страница размечена строго по стандартам W3C без использования безымянных контейнеров:
* `<header>` и `<nav>` — фиксированная шапка и навигационное меню сайта.
* `<main>` — контейнер для основного уникального содержимого.
* `<section>` — логические разделы страницы (`#about`, `#tracks`, `#schedule`, `#signup`), связанные с навигацией через устойчивые ID-якоря.
* `<article>` — независимые карточки учебных модулей.
* `<footer>` — подвал страницы с информацией об авторских правах.

## Применённые CSS-приёмы
* **Сброс стилей:** Использовано правило `box-sizing: border-box` для корректного расчёта размеров элементов с учётом внутренних отступов (padding).
* **Flexbox Layout:** Применён для построения главного меню навигации. Благодаря свойству `flex-wrap: wrap` элементы автоматически переносятся при уменьшении экрана, защищая интерфейс от поломки.
* **Grid Layout (Плитка):** Контейнер карточек спроектирован на сетке CSS Grid с использованием `grid-template-columns: repeat(auto-fill, minmax(300px, 1fr))`, что обеспечивает автоматическое выравнивание блоков по сетке.
* **Адаптивность (Media Queries):** Настроены медиазапросы для планшетов (`768px`) и мобильных телефонов (`480px`), которые перестраивают интерфейс в вертикальные колонки и предотвращают появление горизонтальной прокрутки (скролла).
* **Доступность и Focus:** Отключен стандартный ободок браузера и реализованы плавные кастомные состояния `:focus` и `:focus-visible` для полей ввода и ссылок, что позволяет полноценно управлять сайтом с клавиатуры с помощью клавиши `Tab`.

## Использованные файлы датасета (dataset)
Интерфейс спроектирован на основе предварительного анализа структуры данных:
1. **`navigation.json`:** содержит поля `label` (человекочитаемое название) и `target` (устойчивый идентификатор). Поле `target` послужило основой для создания ID секций и организации якорных ссылок.
2. **`content.csv`:** содержит учебные модули со следующей структурой полей: `id`, `title`, `category`, `description`, `value`. Данные из CSV-файла были структурированы и перенесены в карточки контента (`<article>`) и сводную таблицу (`<table>` с элементами `<thead>` и `<tbody>`).

## Способ локального запуска
Так как в проекте использованы исключительно **относительные пути**, сайт полностью автономен и не требует развёртывания веб-сервера.

1. Склонируйте репозиторий или скачайте архив с проектом.
2. Перейдите в корень каталога `trpo-pr01-merkulova`.
3. Нажмите дважды на файл **`index.html`** — он откроется в любом современном браузере.
4. Для тестирования адаптивности откройте инструменты разработчика (`F12`) и уменьшите ширину viewport.
